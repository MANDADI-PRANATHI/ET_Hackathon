# Document corpus — where to get real, public oil & gas documents

The engine works on **real industrial documents**. Drop files into the folders
below. The synthetic generator (`make synth`) fills the structured folders
(work orders, inspections, permits, quality records) automatically — you add
the real PDFs for the rest.

| Folder | What goes here | Free public sources |
|---|---|---|
| `incidents/` | Incident & investigation reports | **US CSB** investigation reports (csb.gov) — detailed refinery incidents, great for RCA & Lessons-Learned |
| `regulations/` | Safety & quality regulations | **OISD** standards (oisd.gov.in), **OSHA PSM** 29 CFR 1910.119 (osha.gov), Factory Act / PESO docs |
| `manuals/` | Equipment / OEM manuals | Public pump, compressor, valve manuals (manufacturer sites) |
| `procedures/` | SOPs / safe-work procedures | Public refinery SOP samples; some regulators publish templates |
| `operating_instructions/` | Operating instructions | Public operating guides / startup-shutdown procedures |
| `drawings/` | P&IDs / engineering drawings | Public sample P&IDs (ISA / textbook examples) |
| `project_files/` | Project / asset registers | `asset_register.csv` is generated by `make synth` |
| `emails/` | Email archives | Synthesise a few `.eml`/`.txt` threads referencing the asset tags below |
| `work_orders/`, `inspections/`, `permits/`, `quality_records/` | CMMS-style records | **Generated by `make synth`** |

## Keep tags consistent
So everything links up in the graph, reuse these asset tags across any real or
hand-made documents you add (they match what `make synth` produces):

`P-101A`, `P-101B` (crude feed pumps), `V-204` (reflux drum),
`E-301` (preheat exchanger), `C-102` (recycle gas compressor),
`PSV-110A`, `PSV-110B` (pressure safety valves), `FT-150` (flow transmitter).

> Tip: `PSV-110B` is generated with an **overdue** inspection on purpose — it's
> the gap the Level 4a compliance checker should catch in the demo.
